# PDF-translator
PDF translator with format reservation using Google Translator model with python

In this example I am translating to <em>hindi</em>, you can select any languag by changing language/target_lang. 
<br>
make sure proper fonts are loaded for that language,
<em><strong>`NotoSansDevanagari-Regular.ttf`</strong></em> is for Indian languages, including hindi
<br>

Find more fonts [here](https://fonts.google.com/)

# Running the code

Install libraries <em>pikepdf, pymupdf</em> and <em>GoogleTranslator</em>
<br>
```pip install PyMuPDF googletrans==4.0.0-rc1 pikepdf```

I am using <strong>python version 3.12.4</strong>
<br>
translator model has not been updated for newer verisons
